About

I'm a DevOps Engineer working across AWS cloud infrastructure, CI/CD automation, containerization, and monitoring. My day-to-day is Terraform, Docker, Kubernetes, Jenkins and GitHub Actions — turning manual, error-prone releases into pipelines that build, scan, test, and deploy themselves.

I care about the parts of the system that only show up when something breaks: health checks, rollback strategy, backup and restore, and knowing your RTO/RPO before you need them. I also work DevSecOps tooling like Trivy, SonarQube, and OWASP Dependency-Check into pipelines so security checks run on every build, not as an afterthought.
